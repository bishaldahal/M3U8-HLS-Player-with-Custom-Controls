# Building

Requires Node.js 22 or later.

```bash
npm ci
npm run fetch:vendor   # once, and again after changing vendor versions
npm run build          # dist/chrome + dist/firefox
```

## Pipeline (`scripts/build.ts`)

1. `prebuild` renders the PNG icons from `public/icons/icon.svg` with sharp.
2. Vite builds the HTML pages (`src/*.html`) into `dist/<target>/`, copying `public/` along with them.
3. The content and background scripts are built separately as IIFE bundles in `js/`, because content scripts can't be ES modules.
4. `manifest.json` is generated by `buildManifest(target, version)`, with the version taken from `package.json`.

## Packaging

```bash
npm run zip
```

This creates the following in `artifacts/`:

- `m3u8-hls-player-chrome-v<version>.zip`, uploaded to the Chrome Web Store and Edge Add-ons
- `m3u8-hls-player-firefox-v<version>.zip`, uploaded to addons.mozilla.org
- `m3u8-hls-player-source-v<version>.zip`, the source code AMO requires for review

## Reproducing a store build (AMO reviewers)

```bash
unzip m3u8-hls-player-source-v<version>.zip -d src && cd src
npm ci
npm run fetch:vendor   # fails if any downloaded file doesn't match vendor.lock.json
npm run build:firefox
# compare dist/firefox with the submitted package
```
