Keyboard Shortcuts

Changes apply to open players right away.

Click + Add key, then press a key or pick one from the list. Each key can only do one thing; picking a key that is already in use moves it. Number keys (seek to 0–90%) and Esc are fixed.

Site Headers

For streams that answer the player with 403 Forbidden.

Some sites only serve streams to their own pages. Headers listed here are sent with the player's requests to that host and its subdomains.

Remember the page a stream link was opened from
Off by default. When on, clicking a stream link saves that page's address as Referer and Origin for the stream host. Rules you edit are never overwritten.
Detect streams on pages
Lists the streams a page plays in the toolbar popup, so you can open them here with the headers the page used (Referer, cookies, tokens). Needs permission to read request headers. Captured headers stay in memory, are only sent from the player tab, and are cleared when you leave the page.
