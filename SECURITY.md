# Security Policy

## Supported versions

Security fixes go into the latest release published to the browser stores. Older versions are not patched.

## Reporting a vulnerability

**Do not open a public issue.** Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/bishaldahal/M3U8-HLS-Player-with-Custom-Controls/security/advisories/new).

Please include:

- a description of the issue and its impact
- steps to reproduce or a proof of concept
- the affected extension version and browser

You should get an acknowledgement within 7 days. After a fix is released we will credit you in the advisory, unless you'd rather stay anonymous.

## Scope

In scope: the extension's own code in this repository, such as the player, popup, options, background and content scripts, and the build and release pipeline.

Out of scope: vulnerabilities in upstream libraries (report those to hls.js, dash.js or media-chrome directly), and issues that require a compromised browser or machine.
